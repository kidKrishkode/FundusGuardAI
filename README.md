## Introduction
Fundus Guard AI is a autonomus Glaucoma detection system using Deep learning and XAI. This doctor advisor system not predict eye glaucoma but also define why it is consider as glaucoma.

## Aim 🎯  
Our aim is to create an intelligent glaucoma detection platform that:  
1. **Connects** patients, doctors, and medical experts in a unified ai/ml ecosystem.  
2. **Empowers** doctors with AI-driven tools for clear detection, predict explanations, visuals.
